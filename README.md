# TutorPulse

TutorPulse is a planned learning-outcomes service for tutors.

The application will eventually allow tutors to record anonymised assessment results, monitor topic-level performance and identify learners who may benefit from additional support.

## Initial user stories

### Record an anonymised learner

As a tutor, I want to create an anonymised learner record so that I can monitor progress without storing unnecessary personal information.

### Record an assessment result

As a tutor, I want to record an assessment result against a subject and topic so that I can track a learner’s performance over time.

### Review topic-level progress

As a tutor, I want to view a learner’s results grouped by topic so that I can identify areas where additional support may be needed.

## Minimum viable product

The first usable version of TutorPulse will allow a tutor to:

- Create an anonymised learner record
- Create subjects and topics
- Record an assessment date and score
- Associate an assessment with a learner and topic
- View a basic summary of results by learner
- View a basic summary of results by topic

The first version will use synthetic demonstration data and will not store information belonging to real pupils.

## Future ideas

The following features are outside the minimum viable product and may be considered later:

- Predictive machine-learning models
- Tutor and administrator accounts
- Email notifications
- Lesson scheduling
- Payment processing
- Advanced interactive dashboards
- Mobile applications

## Current status

Planning and repository setup.

No application has been implemented yet.

## Privacy

This project will use synthetic or anonymised demonstration data.

No personal information belonging to real pupils will be stored in this repository.
